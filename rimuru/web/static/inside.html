How Rimuru works, live

You talk to one assistant, Rimuru. Behind it, clones do the work, each on one job, and a watchdog makes sure they keep moving. This page shows what came in, what Rimuru decided, and who did what. Click anything for the full story.

What came in

Every message from every channel arrives here first. Simple rules drop the obvious noise for free; only what is left is judged by the AI filter. Your own messages in the chat always go straight to Rimuru.

Conversations

Messages about the same thing - a chat topic, a pull request - are grouped into one conversation. A clone working on it follows the conversation, so follow-ups reach it directly.
