Clones

Conversations

Messages about the same thing - a chat topic, a pull request - form one conversation. A clone working on it follows the conversation, so follow-ups reach it directly.

Watchdog

Checks that clones make progress, not just that they are alive, and nudges the ones that are stuck. When nothing is running it rests and costs nothing.

Want to know how your clones are doing? Type /status in a session's chat - the answer comes at once, from the records.
